# OIL award bug-check walk

This is a walk design, not a claim that any scenario currently fails. Run every destructive scenario from a freshly reset demo world, using the current forward-writing UI. Do not report intentionally discarded pre-build `manual` award records or stale stored demo data as defects.

Use real browser interactions at 1440×900 and 390×844. Keep screenshots before and after each write, and check the browser console after each scenario.

## Fixture key

## Run-level exclusions

Do not file these as defects:

- An old stored `oil:'manual'` war record is dropped on read. D401 requires that outcome.
- A discrepancy that exists only in demo data already stored before this build, where all current UI writes behave correctly.
- The frozen phone overlay not drawing dated day cells; it owns callsign and figure columns, not the scrolled date columns.
- A positive amount other than 0.5 showing `FO`; the exact amount is read in the detail surfaces.
- A tracker award dated outside every war having no grid cell.
- A correction having no FO/HO grid contribution.
- Members seeing other people’s award boxes and figures in the squadron-wide tracker/breakdown surfaces; the prohibition to check here is opening another person’s **grid-award detail** or obtaining an award writer.
