Faults found by the checks, and fixed

The drawing check, the walks and the code readers found these. Each fix began with a test that failed first and passes now. All fixes were walked again on the real app, at desktop and phone size.

  • On a phone, the ☰ menu offered Edit Schedule to someone who can only view 149.
  • Undo of "+ New squadron" jumped Admin to the Users panel. It now lands on Squadrons, where the change shows.
  • The bell's Show buttons could stop working for good after a new squadron was undone.
  • Leave War Approvals' "New" mark was one for all squadrons. It is now one per squadron.
  • With Approvals open, picking the other squadron left the old squadron's requests on the page.
  • Making someone master admin the old way kept his Plan, hidden under "Full access". An Undo could also put a Plan back under the mark. Both are now refused, and the refusal names who made the change.
  • An Admin → Users Save that was refused for a taken sign-in name still saved the access. Now one Save is all or nothing, with one Undo.
  • A 142 admin could answer a request to join 149 by a hand-made save the screen refuses. The save is now refused.
  • Squadron config did not follow the pick. The phone board clipped the day's name. The holiday window was missing its line.
