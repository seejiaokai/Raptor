  with nothing checking it. The two new tests file one for three through the input's own writer and count the cards.

  field, so with the old read the Medical tab would list it under nobody and no test would say so. The new test files
  through `commitNewInput` and asks the three lists.

  `ui/sanscal-model.test.ts` (it hands `sansDayGroups` a record it builds itself). The count's own file,
  `state/sansfly.test.ts`, has no case of one commitment for several people, and the mounted screens' tests
