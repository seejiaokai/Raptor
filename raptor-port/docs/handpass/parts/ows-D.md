## Findings
1. **Off day on an already-issued earning weekend never reaches the day (S39 D2/D3).** Steps: new world; Saturday VIPER 12:00–13:00 with IN TIME 0830; sign, Publish day (FO 08:30–15:00); Leave War → July → event row (EVENT 1) under Sat 18 → "Off day" → Save; back to Edit Schedule. Expected (scenario): credit held until the classification change is issued. Seen: credit held, but Saturday reads no pending, Amendments "No pending changes", no Publish AL (also after reload); the day's changes list unchanged; only Unpublish would remove the credit. (A public holiday declared after a non-earning issue does raise pending — S39.C.) Pictures: dk-30-S39D-sat-offday-day, dk-31-S39D-sat-offday-cell.
2. **Logic line describes work the working copy has excluded (S38.8, pairs Or/Op × Lr/Ld).** With the flight row switched off but not yet issued, changing the debrief adds "OIL on this day · Logic values changed… Ranger full day · 06:00–06:30, 10:00–15:00 → full day · …10:00–15:30" beside "What this day earns changed". The scenario line "a debrief change cannot create an OIL-rule difference where all affected flight work is excluded" reads true only once the exclusion is issued (S38.10b: no line). Possibly intended (the line compares the issued content). RECORDED. Picture: dk-37-S38-8-flightoff-debrief-togoout.
3. Minor: the day switch's visible label stays "Nothing today earns" while it is on (only its tooltip becomes "Let this day earn again"). In OIL Earn on the AVALON desk template, the four empty desk rows each have their own switch; I switched all on.
