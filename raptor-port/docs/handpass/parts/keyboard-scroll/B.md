(3) a second press then a digit → added at the caret, nothing replaced — PASS for all. (4) one press then Backspace → box empty — PASS for all (B9: not emptied, one character removed — as wanted). (5) Tab into the box → see N1.

**N1 — step 5 as worded.** The brief says that after a Tab into a box, typing is "added to". On every text/number box a Tab into it makes *the browser itself* select the whole content (the script reads the selection as 0–N of N), and the first typed key then replaces that selection. A **control** — a plain box that is not on the list (the Duty template's own name box) — does exactly the same at both sizes (rows "B1-control"), so this is not the app arming anything. To tell the two apart I added **step 5b**: Tab into the box, press ArrowRight (collapses the browser's own selection), then type — the digit is **added** in every box at both sizes (PASS everywhere). Read together: a Tab arms nothing. The literal step 5 rows are marked "FAIL as worded (N1)" and counted apart: the same fact repeated 34 times. The Scheduler Board's take-off box (B11) is the exception — a Tab into it puts the caret at the start, not a selection, so its step 5 is a plain PASS ("709:00").

Pictures `desktop-B7-red-s2-left.png`, `desktop-B7-red-s2-reopened.png`, same with `phone-`.
