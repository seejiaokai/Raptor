## (c) FINDINGS

### AB4 — REPRODUCED on screen, both widths, four doors

**What happens.** The owner's rule (27 Aug 26, the clash sheet and the upchit summary): a medical that overlaps a
DIFFERENT-type medical is never resolved silently — before anything is written the filer is asked who holds the shared
days, with no default; an upchit is never saved silently — it shows what it ends and asks Keep / Remove for every later
entry, no default; the leftover of a status taken over is shown with its Remove / Keep before it happens (28 Aug 26). B7:
the same rules at every door. The Inputs page's add form and its ✎ editor and the edit window (Edit Schedule's Unavailable
row → type button) all obey it. **Four doors skip every question and write straight away:**

1. **The Inputs calendar, a downchit chip dragged onto a different-type medical** — writes "the new one replaces" with no
   question (A1: Reaper's HL 20–24 cut to 20–23 by an ATT C dropped on 24).
2. **The same drag inside the old status** — the edit window would show "HL 23–24 will be removed" (its default); the drag
   KEEPS those days without a word (A1f). **The same move gives a different record depending on the door.**
3. **The Inputs calendar, an UPCHIT chip dragged into a medical** — trims the medical and leaves a later medical on file
   without asking Keep / Remove (A2: Piston's OML 20–24 → 20–21, his ATT C 28 Jul kept unasked).
4. **Edit Schedule, the Unavailable row's reassign — arm-then-tap AND palette drag** — moving Cinch's ATT C to Drifter
   silently cuts Drifter's own HL (A3, A3-drag: HL Fri 17–Sat 18 → Sat 18 only).

The same-type refusal DOES fire at all four (B4, A3s); only the two question sheets are missing. Each wrong write is one
undo step, and Undo / Redo / reload behave.

**Reproduce from a fresh world** (admin): Inputs → file HL 20–24 Jul for Reaper and ATT C 18–19 Jul ("No document" both
times) → 📅 Calendar view → ‹ back to July → drag the "Reaper ATT C" chip on 18 Jul onto 24 Jul → "Moved to 24 Jul",
no sheet; the table now reads ATT C 24–25 and HL 20–23. Compare: the table's ✎ on the ATT C → pick 24, 25 → ✓ → the
sheet asks. For the reassign: file ATT C 16–17 Jul for Cinch and HL 17–18 for Drifter → Edit Schedule → Friday →
Unavailable → tap Cinch's puck on the ATT C row → tap Drifter in the crew list → "Drifter is now unavailable instead of
Cinch"; Drifter's HL is now 18 Jul only.

**Rule it breaks:** the owner's 27 Aug 26 "ask at save time" (MedClashConfirm / UpchitConfirm), 28 Aug 26 "never silent"
leftover, and B7 (the same rules at every door). **Pictures:** `w2-01-{desktop,phone}-A1a / A1c / A1d / A1fa / A1fc /
A2a / A2b / A3a / A3b`, `w2-01-desktop-A3d`. **Who it hurts, how:** the admin (or a member on his own chip) — the medical
record decides by itself which status holds a day, drops or keeps days of another status, and ends a medical, where the
owner said a person must choose. MED TOT, the war's medical cells, manning and the Medical view all follow the silent
choice. Scripts: `w2-01-ab4.mjs` (fails while AB4 is there).
