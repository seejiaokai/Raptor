The Events list

Your D1155 asked for a list of the squadron's events. Settings → Events… opens this window. It lists every event on the Event rows over the period picked in View, in date order. An event over several days is one line. Each line is drawn like a line of the Calendar window's Holidays list. The coloured square and word after it are the ones a tap on an event already shows today.

  • ＋ Event opens the event window you already have, ready to pick dates.
  • Edit presets is the same button as in the event window. It is where a kind of event is added (your "add the type of events").
  • A tap on a line opens that event to change or delete it. Past events are greyed, as in the Holidays list.
  • An event with no kind (here EX SHIELD) shows no square, as a tap on it shows none today.
Build as drawn (recommended)No filter chips: a year holds a few dozen events, and fewer buttons keep the window plain.

Importing adds nothing at first. The list shows what the sheet holds: new lines in white marked new, lines already in the app greyed, and any line it cannot read in red, with how to fix it. Where the Management group comes from

Your D1200: Management is a tick column on Quals, added as a group on the Leave War like any Quals column, and it stands first. How should the column get onto Quals?

Already on Quals (recommended)Every squadron starts with an empty Management column, beside SXO. The admin ticks the people. The Leave War knows the column for sure, so a renamed or misspelt column can never stop it standing first.
Added by the adminThe admin adds a column on Quals and names it Management. The Leave War would find it by its name, so a different spelling would not stand first.
