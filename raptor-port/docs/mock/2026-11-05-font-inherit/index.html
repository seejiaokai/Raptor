Letters in eight boxes and buttons

5 Nov 26 · drawn on the real app, today beside the fix

Build it as drawn?

Eight boxes and buttons on the Scheduler Board and the Inputs page show the browser's own letters instead of the app's, because the line that sets their letters is written in a way the browser throws away. The fix writes each line out properly, so each one shows the app's letters, at the size and boldness it was always meant to have.

My recommendation: yes, all of them. They then match every other box and button in the app. The change is small: the words get a little bolder, and some boxes change height by 1 to 4 pixels. Nothing else moves, and the buttons keep their size.

A check goes in with the fix, so a line written this way can't come back unnoticed.

The amber outline marks each place. It is only drawn on these pictures, not part of the design. Both sides of each pair are the same screen. "Fix" is the app's own stylesheet with only these lines corrected.

About the phone pictures: they come from the iPhone's browser engine running on a PC. On this PC, today's boxes show a Windows typeface (the old-style "OL" and "Dentist 0900"). On your iPhone, today's boxes already use Apple's own letters, so there you'll mostly see the words get a little bigger and bolder. Your phone is the final check.

1 · The cancel box on the Scheduler Board

Opened from CX on a line. Today: the browser's letters, regular. Fix: the app's letters, 14, semi-bold. On a desktop the box is 4px taller.

2 · The cancel reasons list

The same box after you press Edit. Each reason's box changes to the app's letters, 12, semi-bold. On a phone each box is 2px shorter, and on a desktop 1px taller.

3 · An input's own window: its boxes, and the person's name

Shown as a member filing his own input. The Type list, the Remarks box and the other boxes change to the app's letters, 13, semi-bold. On a desktop each box is 2px taller. The person's name ("Ranger") already uses the app's letters, so it only gets bolder. The tick box beside "till 5 Nov" doesn't change.

4 · "Several people" and the "All" buttons

In a new input's window. "Several people" changes to 12, semi-bold, and its button gets a little narrower (144 → 135 on a desktop). Each group's "All" changes to 11, semi-bold. Both buttons keep their height.

5 · The "+" on a note, and "+ people" on a new note

In a day opened on the Inputs calendar. The "+" on a note that has people changes to 14, bold, and "+ people" changes to 12, bold. Both keep their size.

And one that isn't on screen

A ninth line of this kind sets the letters for the boxes of the Inputs calendar's old day pop-up. That pop-up has since been replaced by the day window shown in 5, so nothing on screen uses this line. I checked every screen on this page. It gets the same correction with the rest. It changes nothing you can see, and it lets the new check pass.
