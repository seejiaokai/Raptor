Four questions

Q1 · Scheduler Board

On the desktop board, should R and B, and TO and LD, stand one above the other as on the phone?

The picture you marked when you made this ruling was the Scheduler Board on your iPhone. So I have read your "edit schedule" as the board, and drawn your layout there on the phone and the desktop alike (pictures 6 and 10). On a phone it is the only layout that fits. On a desktop it makes each jet's line taller, 51 px to 65 px, so WAVE 1's four lines take about 56 px more.

Recommended: yes, the same on both (picture 10). R is in the same place on every screen, and the board reads the same as the week.

The other way: on a desktop only, R is a fourth box in the line, R · B · TO · LD (picture 11). The lines stay as short as today, but the desktop and the phone are laid out differently.

Q2 · A suggested time inside its box

You asked whether a suggested time could sit in the box's own area. Is this how it should work?

Pictures 4, 6 and 10. The suggested time sits faint, in the blue of today's suggested brief, inside the empty box where the time will go. Nothing sits above the box any more, so the four boxes stay level.

Recommended: one tap on the empty box puts the suggestion in, highlighted, so typing replaces it straight away. Escape takes it back out. Moving through with the Tab key fills nothing, so a suggestion is only taken when someone chooses it. The same for the brief and the rally. View-only Sched still prints an empty brief's suggested time, as today.

Q3 · The default rally's setting

Should the default rally use the Logic page's existing 3-hour setting, or have a setting of its own?

It is partly there already. The Logic page has "Nominal report before T/O", 3 hours. Today that is where a formation's day starts when no in-time or rally is typed, and the time "+ In-time / Rally" fills in. Example: RU takes off at 13:40, so its default rally is 10:40.

Recommended: the same one setting, renamed to say it is the default rally. The rally shown and the time the day starts from can then never disagree. "+ In-time" keeps filling in the same time, as you ruled before.

The other way: a second setting, "Default rally before T/O", beside the nominal report. The two could then be set differently.

Q4 · OIL and the start of the day

Does the R box count for OIL and the day's start exactly like a typed rally does today?

Example: RU has no typed in-time, and the scheduler taps its R box to take 10:40, or types 11:00. RU's day then starts at that time for OIL, crew rest, the long-day warning and Insights' work hours. VL, with in-time 09:40 and R 10:10, starts at 09:40, the earlier of the two. While RU's box is left empty, its day starts at the default, 3 hours before take-off, which is what the app does today.

Recommended: yes. The earliest in-time or rally that applies to the formation starts its day, and an empty box counts as its default. So nothing about OIL moves until a time is typed or taken. On a published day, a changed R box waits for the next amendment, like any other time.

What else changes with it

These are not questions. They are what the build would carry, found while drawing the pictures.

  • Every place the app says "In-time / Rally" for the typed lines says "In-time": the button, the ✕ beside each line, the Logic page's two settings for the button, and the changes window's name for the lines. The warning about timings out of order still names the rally, because it also checks the R box.
  • The next-week peek and a published version's own page draw the same R / B and TO / LD columns.
  • The Excel export gains a Rally column, before Brief.
  • The Tab key goes callsign, mission, rally, brief, take-off, landing.
  • Standby waves (SC, AVALON, BB) get no R box, and wave templates carry none, as they carry no brief.
  • The desktop week's times become one size in both columns (picture 8).
  • A typed line that still says RALLY (out of habit, 19:00H: NIGHT WAVE VL RALLY) counts as VL's in-time, like any other typed line, with no warning. The day's start already uses the earlier of the two, so OIL and crew rest come out the same. My call; tell me if you'd rather the app put a note under the lines.
