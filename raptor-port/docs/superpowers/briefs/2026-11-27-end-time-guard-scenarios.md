# [END-TIME-GUARD] — the walk's scenarios, the two blind lists combined (27 Nov 26, chat 202's night)

Combined by the walk lead (Opus) from two lists written blind to each other: **Astra's** (ids `A01`–`A70`) and **a
fresh, blind Opus in Fable's seat** (ids `T-01`–`T-72`; Fable's own design is owed, his D2819). Duplicates are merged;
every distinct case is kept, with the source id of each. The full wording of each source case stays in its own list —
this file names what is walked and where it came from. Expected results come from the rulings D2612, D2613, D2734,
D2790, D2852, D2853, D2854, D2855 and the plan `docs/superpowers/plans/2026-11-27-end-time-guard-plan.md`.

**Devices.** P = iPhone, 402 wide, WebKit, touch. D = desktop, 1536 wide, Chromium.
**Every state is made through the app's own controls** (bug-check order §7.0, §7.7). A state no control can make is a
missing door, recorded as such; a stored-value case (A46, A47) is carried by a named unit test, never faked.
**FOR HIM** — a case on an open question of the plan's §R5 (R1–R8, Q-W1–Q-W6, Q14–Q21): the build keeps today's
behaviour; the walk pictures what shows and marks it for him, never a pass or a fail (lesson 32).

**The words (D2854).** Sign: "Blocked: N items are missing a time, each outlined in red. Type the missing times, then
sign." — one item: "Blocked: 1 item is missing a time, outlined in red. Type the missing time, then sign." Publish day:
"… <Day> was not published." Publish AL: "… AL<n> was not published." (the AL the press would issue).
