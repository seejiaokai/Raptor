**Fixes applied (the same helper, 7–8 Nov 26, working tree, not committed):** every gap below carries a **Fixed:** note
saying where it is stated now; the account table itself still describes `2cf3fcacc`, before the fixes.

**Codes.** Page sections: **P-head** (the paragraphs before the first heading), **P-Rec** §Records, **P-Mod** §Models and
