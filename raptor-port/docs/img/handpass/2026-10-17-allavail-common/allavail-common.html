Where it lands

A Meeting filed for ALL AVAIL, 13 Jul

Overseas duty needs no change: ALL and ALL AVAIL are never offered for it, so it always stays under Unavailable.

Four questions

What should happen around it?

  • Q1. Moving it. Can a scheduler move it to the Ground Programme and back? I recommend no. It lands on the Common Programme, and Reject still takes it off, as for any input. Moving rows between the two programmes would be a new kind of drag, so it's worth adding only if you find you need it.
  • Q2. When ALL AVAIL comes off. If someone changes the input to named people only, does it move to the Ground Programme (and back again if ALL AVAIL is put back)? I recommend yes. One simple rule: with ALL or ALL AVAIL it is on the Common Programme; without them it is on the Ground Programme.
  • Q3. Which kinds. Every kind that ALL and ALL AVAIL are offered for: Training, Meeting, Appointment, Duty, Event, Personal and Other? I recommend yes, all seven.
  • Q4. Everything else unchanged? The ALL AVAIL count, who stands behind it, its OIL answer, its clashes, and its LATE mark all work exactly as they do now. Only the place changes. I recommend yes.

Moving on a day that is already published would read "1 pending" there once. That only affects the demo data, which is cleared before the database.

How to answer

For example: Q1–Q4 as recommended. There's no rush. I'm building the till-date work first either way.
